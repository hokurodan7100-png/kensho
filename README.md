# 懸賞マネージャー

Web フォーム応募型の懸賞を **集める → 管理する → 応募フォームを自動入力する** ための、PC 用 Web アプリです。
家の PC で 24 時間動かすと、**集める・事前チェック・（承認したものの）送信・LINE 通知** を自動で行います。

## 24 時間運用の流れ

```
[ワーカー] 収集（6 時間ごと）→ 応募ページを開いて事前チェック
              ├─ 全部自動で入力できた  → 送信待ち ──LINE 通知──┐
              └─ 画像認証・ログイン・   → 手動で応募            │
                 入力できない必須項目など                        ▼
[あなた]                               管理画面「承認」で内容を確認して承認
[ワーカー] 承認された懸賞だけ送信（確認画面にも対応）→ 完了画面を確認 → 応募済み
              └─ 完了を確認できない・ページが変わった → 手動で応募（理由つき）
```

- **承認していない懸賞は送信しません。** 承認のときに、入力内容・チェックを入れる項目（規約同意）・押すボタンを確認できます。
- 承認したときと入力内容が変わっていたら送信しません。
- 画像認証（CAPTCHA）は突破しません。表示されたら「手動で応募」に回します。
- 二重応募を防ぐため、ボタンを押しても入力画面のままなら、それ以上押しません。完了を確認できなかったものは自動で再送しません。
- 送信後の画面はスクリーンショットとして `screenshots/` に残り、一覧の「画面を見る」から確認できます。
- **応募規約で自動での応募を禁止している懸賞は承認しないでください。** 当選が無効になることがあります。

- **収集**：懸賞まとめサイトなどの RSS/Atom を登録しておくと、新しい懸賞を取り込み、本文から締切日を推定します。キーワードで絞り込みや除外もできます。
- **管理**：未応募／応募済み／当選／落選／スキップを記録します。締切が 3 日以内の懸賞は画面の上に表示します。
- **自動入力**：「✍️ 自動入力で開く」を押すと Chrome が開き、登録したプロフィールでフォームを埋めます。
  - 送信ボタンは押しません。内容と応募規約を確認して、**自分で送信**してください。
  - 規約同意のチェック、CAPTCHA、パスワード欄、ファイル欄には触れません。
  - 入力できた欄は緑、推測できなかった欄は黄色の枠で表示します。

> 多くの懸賞は規約で自動応募や bot での応募を禁止しています。このツールは入力の手間を減らすためのもので、送信は必ず自分で行う作りにしています。

## セットアップ

### かんたんセットアップ（おすすめ）

1. [Python](https://www.python.org/downloads/) 3.10 以上を入れる（Windows はインストール画面で「Add python.exe to PATH」にチェック）
2. このリポジトリをダウンロードする（GitHub の緑の「Code」→「Download ZIP」で展開するか、`git clone`）
3. フォルダの中の次のファイルをダブルクリックする
   - Windows：`setup_windows.bat`
   - Mac：`setup_mac.command`（初回は右クリック→「開く」）
4. 「セットアップが終わりました」と出たら、`start_windows.bat`（Mac は `start_mac.command`）をダブルクリックする
5. ブラウザで http://127.0.0.1:5000 を開き、まず「プロフィール」を登録する

### 手動でセットアップする場合

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
playwright install chromium      # Chrome が入っていれば不要（普段の Chrome を使います）
python app.py                    # 管理画面
python worker.py                 # ワーカー（別のウィンドウで）
```

## 使い方

1. 「収集元」に RSS の URL を登録し、一覧の「🔄 収集元から取り込む」を押す（または「＋ 追加」で手動登録）
2. 応募したい懸賞の「✍️ 自動入力で開く」を押す
3. 開いたブラウザで黄色の欄を手で入力し、内容を確認して送信する
4. 管理画面に戻って「応募済み」を押す。結果が出たら「当選」か「落選」を押す

自動入力用のブラウザは `browser_profile/` にログイン状態を保存するので、会員登録が必要なサイトも 2 回目からは楽になります。

## 家の PC で 24 時間動かす

管理画面（`app.py`）とワーカー（`worker.py`）の 2 つを動かします。

```bash
python app.py       # 管理画面
python worker.py    # ワーカー（別のウィンドウで）
```

管理画面の右上が「● ワーカー動作中」になれば OK です。

### PC を起動したら自動で動かす

**Windows**
1. 「タスク スケジューラ」を開き、「基本タスクの作成」を選ぶ
2. トリガーは「ログオン時」、操作は「プログラムの開始」で、`start_windows.bat` を指定する
3. 「設定」→「システム」→「電源」で、電源接続時のスリープを「なし」にする

**Mac**
1. 「システム設定」→「一般」→「ログイン項目」に `start_mac.command` を追加する
2. ワーカーの動作中は、スリープしないようになっています（`caffeinate`）

ワーカーの状態と記録は、管理画面の「設定」で確認できます。

## LINE 通知の設定

LINE Notify は終了したため、自分専用の LINE 公式アカウントを作り、そこから自分に通知を送ります。

1. [LINE Developers](https://developers.line.biz/) に LINE アカウントでログインし、プロバイダーを作る
2. 案内に従って **Messaging API** のチャネル（LINE 公式アカウント）を作る
3. チャネルの「Messaging API 設定」で、**チャネルアクセストークン（長期）** を発行する
4. 「チャネル基本設定」の一番下にある **あなたのユーザー ID**（U から始まる）を控える
5. 「Messaging API 設定」の QR コードから、その公式アカウントを友だち追加する
6. 管理画面の「設定」にトークンとユーザー ID を入れて保存し、「LINE にテスト通知を送る」を押す

通知は次のときに、1 回の確認につき 1 通にまとめて送ります。
- 送信待ちが増えたとき
- 送信の結果（失敗があったとき、その懸賞の名前も）
- 毎日のまとめ（既定は 20 時。送信待ちの件数、締切 3 日以内の懸賞）

無料プランは 1 か月に送れる通数に上限があります。通知が多すぎる場合は、「設定」で取り込みの間隔を長くしてください。

## うまく動かないとき

- **「別のブラウザが使用中」と出る**：自動入力用のブラウザのウィンドウをすべて閉じてから、もう一度押してください。見当たらない場合は、タスクマネージャー（Mac はアクティビティモニタ）で Chrome を終了してください。
  自動入力用のブラウザが開いているときにもう一度押すと、そのウィンドウの新しいタブで開きます。
- **「ブラウザを起動できませんでした」と出る**：Google Chrome をインストールするか、`playwright install chromium` を実行してください。
- 詳しいエラーは `autofill.log` に記録されます。
- **「応募フォームが見つかりません」で手動になる**：収集した URL が記事ページで、応募ページへのリンクを辿れなかった場合です。「編集」で URL を応募フォームのページに直すと、次の取り込みのときに再チェックされます。
- **ワーカーが停止中のまま**：`worker.py` のウィンドウにエラーが出ていないか確認してください。二重起動は防いでいるので、もう一度起動しても大丈夫です。

## データ

- `kensho.db`：懸賞・プロフィールなど（SQLite）。外部には送信しません。
- 管理画面は `127.0.0.1` だけで待ち受け、すべての POST に CSRF トークンを付けているので、他のサイトから操作されることはありません。

## 環境変数

| 変数 | 説明 |
|---|---|
| `KENSHO_DB` | DB ファイルの場所 |
| `KENSHO_BROWSER_CHANNEL` | 使うブラウザ（既定 `chrome`、`msedge` など。見つからなければ Playwright の Chromium） |
| `KENSHO_BROWSER_PATH` | 使うブラウザの実行ファイルを直接指定 |
| `KENSHO_CDP_PORT` | 開いているブラウザへの接続に使うポート（既定 9333） |
| `PORT` | 管理画面のポート（既定 5000） |
